## What it runs

Every [commerce model](/guides/commerce-models/): B2B, B2C, direct to consumer, marketplace, subscription,
procurement and replenishment, from any channel. Each model starts from a [built-in flow](/guides/templates/)
you can open in the editor, change and republish.

- **Flows are data.** A flow is a JSON graph of [catalog nodes](/reference/nodes/). Publishing makes an
  immutable version, and each order pins the version it started on.
- **Orders are durable.** Each node runs once and its result is kept, so an order survives
  restarts, waits days for a person or a payment, and rolls back its reservations, holds and
  shipments when it fails.
- **Every order is live.** The order page shows each node as it runs, and approvals and events
  reach the waiting node from the dashboard, the API, a signed webhook or the assistant.
- **AI never blocks an order.** Every model call has a schema, a 20-second cap and a deterministic
  fallback.
