This page is rendered from `NODE_SPECS` in `packages/core/src/catalog.ts` when the docs are built,
the same objects the editor's palette, the inspector's forms and the engine's validation read. Each
node's anchor is its type, for example [`#commerce.policy`](#commerce.policy).

A node's **outputs** are the branches it can take. An edge leaves a node from one output (its
`sourceHandle`; none means `out`), and the edges on the branches a node did not take are skipped
(see [Planner](/internals/planner/)). Field **kinds** decide how the inspector edits a value and how
it is validated: `duration` is a string like `"2 days"`, `logic` is a
[JSON Logic expression](/reference/expressions/), `list` is a non-empty list of strings, and text
fields interpolate `{{path}}` templates.

Every node also takes two optional settings outside its config: `retries` (0–10, default 3 unless
the node type sets its own) and `timeout` (default `"5 minutes"`), applied to its step.
