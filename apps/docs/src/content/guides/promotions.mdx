---
title: Promotions
description: Promotion codes that take a percentage or an amount off, or make shipping free, with limits on who can use them and how often, applied by a flow's Apply promotions step.
---

A promotion is a code, such as `WELCOME15`. An order carries its codes in `meta.promoCodes` (set
by whoever starts it, for example through the REST API); when it runs, its flow's
[Apply promotions](/reference/nodes/#commerce.discount) step checks each code and applies it.

## Creating codes

Operators manage codes on **Promotions** (linked from the Pricing section of **Commerce**). A code
is letters, digits, dashes and underscores, up to 32, and is matched however it's typed
(` welcome15 ` is `WELCOME15`). Each code takes off one of:

| Takes off | What changes |
|---|---|
| **A percentage** | The prices of the lines it covers, by that percentage |
| **An amount** | That amount, spread over the lines it covers in proportion to their value, never more than they are worth. In the base currency, converted at the order's rate |
| **Shipping** | The order's shipping charge, to zero |

and can be limited to:

- **Only these SKUs**: it covers only those lines.
- **Only this customer**.
- **A minimum subtotal**, in the base currency.
- **Uses in all** and **uses per customer**: each order that keeps a code uses it once.
- **An end date**.

**Pause** stops a code applying to new orders; **Resume** lets it apply again. The **Used**
column counts the orders that have used it.

## In a flow

The built-in Storefront, Omnichannel and B2B order flows already have a **Promotions** step in
place. A workspace that already had those flows keeps its own versions: publish a new version
with the step to use codes there. On other flows, add **Apply promotions** after **Price lines**,
and before **Calculate tax** so tax is worked out on the discounted prices. For free shipping, place it after **Shipping rate** too. With
**Stack codes** off (the default) only the code worth the most applies; on, every code that
applies is used, each on the prices the one before left.

A code that doesn't apply (unknown, paused, expired, for another customer, below its minimum,
covering nothing in the order, or used up) is left out, and the step's result on the order page says why. A
[cart](/guides/carts/) is priced by its flow's steps, Apply promotions included, so a cart's
total is what its order charges.

A code counts as used only when an order applies it, and two orders racing for a code's last use
can't both have it. If the order later fails and rolls back, or is cancelled, its uses are given
back.
